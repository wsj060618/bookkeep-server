# 部署操作步骤

服务器：`81.71.140.152`（Debian 13 + Docker）。按顺序执行，每步都给了预期结果。

## 1. 安全组

腾讯云控制台 → 安全组 → 入站规则，加两条：

| 协议 | 端口 | 来源 |
|---|---|---|
| TCP | 22 | 你的 IP |
| TCP | 80 | 0.0.0.0/0 |

不要加 3306 / 8080 / 443。

## 2. 本地打包

```powershell
cd D:\coding\bookkeep-server
mvn -pl bookkeep-web -am -DskipTests clean package

cd D:\coding\bookkeep-web
npm run build
```

把产物放成这个结构再压缩（或直接用 `deploy\bookkeep-cloud.zip`）：

```
bookkeep-server/
  docker/                  docker-compose.yml / Dockerfile / nginx.conf / .env
  bookkeep-web/target/bookkeep.jar
  bookkeep-web/dist/
  sql/schema.sql
```

## 3. 上传

```powershell
scp D:\coding\bookkeep-server\deploy\bookkeep-cloud.zip root@81.71.140.152:/opt/
```

## 4. 解压

```bash
cd /opt
unzip -q bookkeep-cloud.zip
cd /opt/bookkeep-server/docker
```

预期：`/opt/bookkeep-server`、`/opt/README.md` 存在。

## 5. 改配置

```bash
vi .env
```

只改这两处：

```bash
APP_BASE_URL=http://81.71.140.152

# 要用「找回密码」才填，否则留空
MAIL_USERNAME=
MAIL_PASSWORD=
MAIL_FROM=
```

`MYSQL_ROOT_PASSWORD` / `DB_PWD` / `JWT_SECRET` 已生成，不要改。

## 6. 启动

```bash
docker compose up -d --build
docker compose ps
```

预期：`mysql` 是 `healthy`，`app` 和 `nginx` 是 `Up`。首次约 2–5 分钟。

## 7. 验证

```bash
curl -I http://127.0.0.1/
docker compose exec -T mysql sh -c 'mysql -uroot -p"$MYSQL_ROOT_PASSWORD" -N -e "show tables" bookkeep' | wc -l
docker compose logs --tail=20 app
```

预期：

- `HTTP/1.1 200 OK`
- 表数量 `10`
- 日志有 `启动成功 ... 端口: 8080 环境: prod`

浏览器打开 `http://81.71.140.152/`，注册 → 记一笔 → 传票据 → 分享，看能否正常。

## 8. 连数据库（可选）

```bash
cd /opt/bookkeep-server/docker
docker compose exec mysql sh -c 'mysql -uroot -p"$MYSQL_ROOT_PASSWORD" bookkeep'
```

Navicat：本机执行 `ssh -L 3307:127.0.0.1:3306 root@81.71.140.152`，再连 `127.0.0.1:3307`。

## 9. 备份

```bash
cd /opt/bookkeep-server/docker
docker compose exec -T mysql sh -c 'mysqldump -uroot -p"$MYSQL_ROOT_PASSWORD" --single-transaction --default-character-set=utf8mb4 bookkeep' > /opt/backup-$(date +%F).sql
docker compose exec -T app tar czf - -C /app/data receipts > /opt/receipts-$(date +%F).tgz
```

恢复：

```bash
docker compose exec -T mysql sh -c 'mysql -uroot -p"$MYSQL_ROOT_PASSWORD" bookkeep' < /opt/backup-2026-11-10.sql
docker compose cp /opt/receipts-2026-11-10.tgz app:/tmp/
docker compose exec app tar xzf /tmp/receipts-2026-11-10.tgz -C /app/data
```

## 10. 停止 / 重启

```bash
docker compose restart app     # 改完 .env
docker compose down            # 停（数据保留）
docker compose down -v         # 连数据一起删，别用
```
